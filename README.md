## ЛР1

Вариант 4: IoT Sensor Data. Используется датасет по ссылке из задания:
[IoT dataset for Intrusion Detection Systems (IDS)](https://www.kaggle.com/datasets/azalhowaide/iot-dataset-for-intrusion-detection-systems-ids),
файл `BoTNeTIoT-L01-v2.csv`. Бизнес-сценарий №4 — анализ логов и мониторинг,
цель проекта: снижение MTTR на 40%.

В отчёте отдельно обозначаются измеренные свойства CSV, модельные расчёты
нагрузки и экономические допущения. CSV не содержит времени событий и журналов
реальных инцидентов: историческую скорость поступления и достигнутое снижение
MTTR по нему определить нельзя.

Полный отчёт, команды воспроизведения и карта соответствия пунктам задания
находятся в [материалах ЛР1](lab1/README.md) и [матрице требований](lab1/requirements_checklist.md). Данные и окружения остаются
в игнорируемых `data/` и `.venv/`.
